# Languages

A personal collection of language-learning notes and reference material.

## Contents

### Japanese

- [Japanese vocabulary](japanese_vocab.md) — a growing vocabulary list with readings, English meanings, word types, example sentences, translations, and usage notes.

## Vocabulary format

The Japanese vocabulary list uses the following columns:

| Column | Description |
| --- | --- |
| Word | The word in its usual Japanese spelling |
| Hiragana | The word's reading |
| Meaning in English | One or more common English meanings |
| Type of Word | Grammatical category, such as noun, verb, or adjective |
| Example Used in a Sentence | A natural Japanese example sentence |
| Example English Translation | English translation of the example |
| Notes | Usage guidance, nuance, or related grammar |

## Using the collection

Browse the vocabulary file directly on GitHub, or clone the repository to search and edit it locally:

```bash
git clone git@github.com:kevinc16/languages.git
cd languages
```

Because the files are plain Markdown, they work well in any text editor and render automatically on GitHub.

## Contributing

When adding vocabulary, keep entries in the existing table format and include a reading, an example sentence, and a clear English translation whenever possible.
